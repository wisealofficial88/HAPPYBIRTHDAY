===================================================================
CUSTOM BACKGROUND MUSIC INSTRUCTIONS:
===================================================================

To play your own song/music in the website:
1. Drop your audio file (e.g. "music.mp3") into this "public" folder.
   Its path should be:
   C:\Users\aakas\Desktop\BDAY\public\music.mp3

2. The website is already configured to automatically play "music.mp3"!
   (If your file has a different name, like "song.mp3", open "src/config.js"
   and change:
   customMusicPath: '/song.mp3')

3. If no file is placed in this folder, the website automatically plays
   the built-in peaceful fairytale music-box lullaby.
